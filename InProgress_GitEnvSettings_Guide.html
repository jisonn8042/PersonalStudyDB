Ⅰ. ssh設定-1つのGitHubアカウントを連携する場合

1. sshキー生成

GitHubと連携するためのsshキーを生成します。

生成

# -f を活用し任意の名前でキーを生成します。
ssh-keygen -t ed25519 -C "[GitHubメールアドレス]" -f ~/.ssh/id_ed25519_[任意の名前]

#入力例
ssh-keygen -t ed25519 -C "example@example.com" -f ~/.ssh/id_ed25519_personal-github

確認

#コマンドを入力時[任意の名前]になっているファイルの有無を確認します。
ls -al ~/.ssh


2. ~/.ssh/config生成・設定

~/.ssh/configファイルを生成・設定します。

設定

#~/.sshにディレクトリ移動
cd ~/.ssh

#~/.ssh/configファイルを生成
touch config

#configファイルを開く
open config

#~/.ssh/configファイルを設定
Host [別名]                                          # 別名
    HostName github.com                              # ホスト名
    User git                                         # User名
    IdentityFile ~/.ssh/id_ed25519_[任意の名前]      # 作成したsshキー
    UseKeychain yes                                  # キーチェインを使用する
    AddKeysToAgent yes                               # エージェントにキーを追加する

#入力例
# ----------------------------
# 1. 個人用 アカウント (alias(別名)を使用)
# ----------------------------
Host personal-github                      
    HostName github.com                   
    User git                              
    IdentityFile ~/.ssh/id_ed25519_personal-github   # 個人アカウント用生成したキー
    UseKeychain yes                       
    AddKeysToAgent yes

さらにconfigファイルは、セキュリティのため権限を制限する必要があります。

設定

#~/.ssh/configファイルの権限を変更
chmod 600 ~/.ssh/config                              # 600:所有者のみ読み書きができる

確認

#~/.ssh/configファイルの権限を確認
ls -al ~/.ssh/config                                 # 結果の最初の部分に-rw-------と表示されていることを確認

#結果例
-rw-------  1   staff  1024  12  4 15:42 ~/.ssh/config


3. GitHubにsshキーを登録

GitHubにsshキーを登録します。

設定

1. sshキーをコピーします。

#GitHubにsshキーを登録
cat ~/.ssh/id_ed25519_[任意の名前].pub | pbcopy

#入力例
cat ~/.ssh/id_ed25519_personal-github.pub | pbcopy

2. GitHubのSettingsに移動して、SSH and GPG keysに移動します。

3. "New SSH key"を押して、タイトルとキーを入力します。

4. タイトルは任意で、キーはコピーしたものを貼り付けます。

5. "Add SSH key"を押します。



4. リポジトリをクローンして連携確認

リポジトリをクローンして連携確認を行います。
クローンする時、ssh URLの前の github.com 部分を通信するアカウントに合うalias(別名)に書き換えてください。

変更前

git@github.com~

# 変更前例
git@github.com~

変更後

git@[alias(別名)]~

# 変更後例
git@personal-github~

確認

git clone [変更後repository ssh URL]    

# 入力例
git clone git@personal-github~


5.注意点

ssh URLの書き方

ssh URLの前の github.com 部分を通信するアカウントに合うalias(別名)に書き換えてください。

変更例

git@[alias(別名)]~

# 変更前例
git@github.com~

# 変更後例
git@personal-github~


Ⅱ. ssh設定-複数のGitHubアカウントを連携する場合

ssh通信に使うURLは[ユーザ名]@[ホスト名]...の形式になっています。
1つのgithubアカウントだけ連携して通信する場合は、同じユーザ(git)に対し、1つのキーで通信するので大丈夫ですが、複数のアカウントを連携する場合は、アカウント別に通信に合う異なるキーを使用する必要があります。

その為、sshは通信時、~/.ssh/configファイルを参照して行いますが、
そのconfigファイルにalias別に使用するキーを設定しておくことで、ssh URLを書く時、ホスト名(github.com)の代わりにaliasを書いて、状況別に通信に異なるキーを使用することができます。

この章では、1章とほとんど同じですが、複数のGitHubアカウントを正しく連携する為の~/.ssh/configファイルの設定や、aliasを活用したssh URLの書き方を追加して説明します。


1. sshキー生成

GitHubと連携するためのsshキーを生成します。

生成

# -f を活用し任意の名前でキーを生成します。
ssh-keygen -t ed25519 -C "[GitHub用メールアドレス]" -f ~/.ssh/id_ed25519_[任意の名前]

#入力例
ssh-keygen -t ed25519 -C "example@example.com" -f ~/.ssh/id_ed25519_different-github

確認

#コマンドを入力時任意の名前になっているファイルの有無を確認します。
ls -al ~/.ssh


2. ~/.ssh/config生成・設定

~/.ssh/configファイルを生成・設定します。

複数のアカウントを連携している場合、たまにalias(別名)を設定しても同じUser名（git）に対して、どの鍵を使用すべきか自動判別できない場合があります。
その時、alias(別名)にIdentitiesOnly yesを作成しておくと、ssh通信の時、ssh URLのホスト部分がそのalias(別名)になっている場合、指定されたキー以外は使用しないように制限します。

設定

#~/.sshにディレクトリ移動
cd ~/.ssh

#~/.ssh/configファイルを生成
touch config

#configファイルを開く
open config

#~/.ssh/configファイルを設定
Host [別名]                                          # 別名
    HostName github.com                              # ホスト名
    User git                                         # User名
    IdentityFile ~/.ssh/id_ed25519_[任意の名前]      # 作成したsshキー
    IdentitiesOnly yes                               # 同じUser名に対して異なるsshキーを使用する
    UseKeychain yes                                  # キーチェインを使用する
    AddKeysToAgent yes                               # エージェントにキーを追加する

#入力例
# ----------------------------
# 1. 会社用 アカウント (基本値として設定する場合が多い)
# ----------------------------
Host github.com
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_work              # 会社アカウント用生成したキー
    IdentitiesOnly yes  
    UseKeychain yes
    AddKeysToAgent yes

# ----------------------------
# 2. 個人用 アカウント (alias(別名)を使用)
# ----------------------------
Host personal-github                      
    HostName github.com                   
    User git                              
    IdentityFile ~/.ssh/id_ed25519_personal-github   # 個人アカウント用生成したキー
    IdentitiesOnly yes                    
    UseKeychain yes                       
    AddKeysToAgent yes 

# ----------------------------
# 3. 他のアカウント (alias(別名)を使用)
# ----------------------------
Host different-github                     
    HostName github.com                   
    User git                              
    IdentityFile ~/.ssh/id_ed25519_different-github  # 他のアカウント用で生成したキー
    IdentitiesOnly yes                    
    UseKeychain yes                       
    AddKeysToAgent yes

さらにconfigファイルは、セキュリティのため権限を制限する必要があります。

設定

#~/.ssh/configファイルの権限を変更
chmod 600 ~/.ssh/config                              # 600:所有者のみ読み書きができる

確認

#~/.ssh/configファイルの権限を確認
ls -al ~/.ssh/config                                 # 結果の最初の部分に-rw-------と表示されていることを確認

#結果例
-rw-------  1   staff  1024  12  4 15:42 ~/.ssh/config


3. GitHubにsshキーを登録

GitHubにsshキーを登録します。

設定

#GitHubにsshキーを登録
cat ~/.ssh/id_ed25519_[任意の名前].pub | pbcopy

#入力例
cat ~/.ssh/id_ed25519_different-github.pub | pbcopy


4. リポジトリをクローンして連携確認

リポジトリをクローンして連携確認を行います。
クローンする時、ssh URLの前の github.com 部分を通信するアカウントに合うalias(別名)に書き換えてください。

変更前

# 変更前例
git@github.com~

変更後

# 変更後例
git@different-github~

確認

git clone [変更後repository ssh URL]    

# 入力例

5. 注意点

ssh URLの書き方

ssh URLの前の github.com 部分を通信するアカウントに合うalias(別名)に書き換えてください。

変更例

# 変更前例

# 変更後例

ローカルGit設定

ローカルGit設定は、コミット履歴に正しい情報を表示するための設定を行います。
設定はプロジェクトのルートディレクトリで行います。

設定

#ローカルGit設定
git config --local user.name [名前]
git config --local user.email [GitHubメールアドレス]

#入力例
git config --local user.name example
git config --local user.email example@example.com

確認

#Git設定確認
git config --local user.name
git config --local user.email
